# Guides

These guides cover common Zelta workflows. Start with direct `zelta backup` and `zelta match` commands, then move repeated work into `zelta policy`.

- [Simple Backups](/guides/backup): Create and verify direct backups.
- [Policy-Based Automatic Backups](/guides/policy): Run multiple backup jobs from configuration.
- [Zelta Twin](/guides/twin): Build asynchronous cluster pairs from reciprocal backups and guarded failover.
- [Failover Workflows](/guides/sync): Use backup, lock/unlock, propsync, and failover for active-passive systems.
- [Rollback & Recovery](/guides/recovery): Use snapshots, clones, revert, and rotate for safe recovery.
- [JSON Output](/guides/json): Capture machine-readable output for monitoring.

For installation and delegation, see [Installation & Configuration](/home/install), [SSH Configuration](/conf/ssh), and [ZFS Allow Delegation](/conf/zfs-allow).
